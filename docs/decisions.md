## D1. 채널 자동화는 완료 기준이 아니다

**결정** — 1차 버전의 **정식 발행 경로는 "내보내기"**다.
이미지 폴더 열기 + 제목/본문/캡션/해시태그 원클릭 복사 + 업로드 체크리스트.

브라우저 자동화(네이버 임시저장, 인스타 Business Suite 입력)는 **실험 기능(베타)
토글**로 넣고, 실패하면 자동으로 정식 경로로 떨어진다. 원래 계획의 "입력 실패 시
폴더 열기·문구 복사 제공"을 예외 처리가 아니라 **기본값으로 승격**시킨 것이다.

**근거**
- 네이버 스마트에디터 ONE은 중첩 iframe·동적 DOM이라 셀렉터가 수시로 깨진다.
  "임시저장 후 다시 열어 확인"하는 검증 로직도 같은 DOM에 의존하므로,
  화면이 바뀌면 **작성과 검증이 동시에** 실패한다.
- 두 서비스 모두 약관에 자동화 접근 제한이 있고, 1인 운영자에게 계정 정지는 치명적이다.
- Instagram Graph API는 **예약 발행을 지원하지 않는다.** 그래서 화면 자동화를 택한
  것은 논리적으로 맞지만, 동시에 API로 우회할 수도 없다는 뜻이다.

**따라오는 것**
- 셀렉터는 코드에 박지 않고 **외부 JSON 프로필로 분리**한다. 네이버가 화면을 바꿔도
  앱 재배포 없이 프로필만 갱신한다.
- 완료 기준을 "네이버 임시저장·인스타 예약 입력까지 이어지는 것"에서
  **"두 채널 발행 자료가 붙여넣기 가능한 형태로 완성되는 것"**으로 바꾼다.
- 재사용하려던 기존 업로더 코드의 위치·상태·마지막 동작 확인 시점을 확인해야 한다.
  (현재 이 저장소에는 없다.)

## D2. 합성은 HTML/CSS 단일 경로, 폰트는 Pretendard 1종

**결정** — 문구·로고·레이아웃은 HTML/CSS로 조판해 Chromium으로 캡처한다.
Sharp는 사진 전처리 전용. 폰트는 Pretendard(SIL OFL) 한 종.

상세 근거와 캡처 규약은 [`templates/README.md`](../templates/README.md),
폰트 선정 근거는 [`templates/fonts/README.md`](../templates/fonts/README.md).

**주의 — 대안 관계가 아니다.** HTML/CSS와 gpt-image-2는 서로 바꿔 쓰는 선택지가
아니라 순차 단계다. gpt-image-2가 배경을 만들고, HTML/CSS가 그 위에 한글을 얹는다.
"결과가 별로면 카드 전체를 AI에게 그리게 한다"는 대체 경로는 두지 않는다.
한글 자모가 깨지고, 문구 수정이 불가능해지기 때문이다(재생성마다 그림이 달라진다).

## D3. 이미지는 gpt-image-2 / medium / 세로, 모델 ID는 설정 파일로

**결정**

| 항목 | 값 |
|---|---|
| 이미지 모델 | `gpt-image-2` |
| 품질 | `medium` 고정 |
| 비율 | 세로 4:5 (1080×1350 목표) |
| 기본 공급자 | OpenAI 유지 (Gemini는 수동 선택 대체 경로) |
| 모델 ID·단가·품질 | 소스 하드코딩 금지 → `config/providers.json` |

**근거**

*모델* — `gpt-image-1`은 **2026-10-23**, `gpt-image-1.5`·`gpt-image-1-mini`는
**2026-12-01**에 API에서 내려간다. 둘 다 대체 모델은 `gpt-image-2`다.
1.5는 12월에 같이 죽으므로 징검다리로 쓸 이유가 없다.

*하드코딩 금지* — 이미지 모델은 6~12개월 주기로 은퇴하는데 이 앱은 설치형이라
코드가 사용자 PC에 박혀 있다. 모델 ID를 소스에 넣으면 은퇴할 때마다 전체 재배포가
필요하고, 업데이트 안 한 사용자는 앱이 그냥 고장 난다. D1의 "셀렉터를 JSON으로
분리"와 같은 구조다.
→ **깨지는 요소가 네이버 DOM과 AI 모델 ID 두 개나 되므로 자동 업데이트가 필수다.**

*medium 고정* — 이미지 품질을 high로 올리는 통상적 이유는 글자가 깨지기 때문인데,
D2에 따라 **한글 문구는 앱이 직접 합성**한다. 모델은 배경·분위기만 그리면 되므로
글자 렌더링에 장당 4배를 낼 이유가 없다.

*비용 추정* (2026-09 공개 자료 기준, 착수 전 공식 가격표 재확인 필요)

| 모델 | 장당 |
|---|---|
| gpt-image-2 low | ~$0.006 |
| **gpt-image-2 medium (세로)** | **~$0.041** |
| gpt-image-2 high (세로) | ~$0.165 |
| Gemini 2.5 Flash Image | ~$0.039 |

1프로젝트 최대치(블로그 4장 + 카드 배경 7장 = 11장) 기준 **$0.45 내외 + 원고 비용**.
사용자가 자기 사진을 넣으면 더 내려간다.

*OpenAI 기본 유지* — "키 하나로 전체 제작"의 가치가 크다. 1인 운영자에게 API 키를
두 개 발급받고 각각 결제수단을 등록하는 일은 실질적 진입장벽이다.
단, 조직 인증 403 문제가 실재하므로 1단계에서 확인한다(T1).

*Gemini 추상화* — 자동 전환은 하지 않는다(계획 원칙 유지). 다만 `ImageProvider`를
형식적이 아니라 **진짜로 추상화**해 둔다. 모델 은퇴·403·가격 인상 세 가지에 대한
공통 보험이다.
