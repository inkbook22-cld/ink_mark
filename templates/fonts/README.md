# 폰트

이 폴더에 아래 파일을 넣는다. **저장소에는 커밋하지 않고 빌드 시 받아서 넣는다**
(바이너리 비대화 방지 + 라이선스 원문을 함께 배포하기 위함).

- `Pretendard-Regular.woff2`
- `Pretendard-SemiBold.woff2`
- `Pretendard-ExtraBold.woff2`

## 폰트를 Pretendard 1종으로 고정한 이유

- **재배포·임베딩 허용 (SIL OFL).** 설치 파일에 폰트를 동봉해 배포하므로 단순
  "무료"가 아니라 재배포가 명시적으로 허용되어야 한다.
- **굵기 9종.** 카드뉴스 제목에는 ExtraBold급이 필요하다. Regular/Bold 2종만 있는
  폰트로는 위계가 안 만들어진다.
- **한영 혼용.** 가격·날짜·브랜드 영문이 섞이는데 영문·숫자 품질이 좋다.

폰트를 2종 이상 쓰면 템플릿 3종 × 폰트 조합으로 검증 대상이 곱해진다.
굵기와 크기만으로 위계를 만드는 편이 한글 카드뉴스에서는 오히려 깔끔하다.

브랜드별 폰트 요구는 나중에 **"사용자가 자기 폰트 파일 추가"** 기능으로 연다.
라이선스 책임이 사용자에게 가므로 배포자가 안전하다.

## 금지

상용 폰트(윤고딕·산돌 등)는 앱 임베딩 배포에 별도 계약이 필요하다. 넣지 않는다.
